> **调整规则只改本文件**（脚本会自动读取下方机检配置区），不必改脚本、不必重发全文。

## 0 · 总原则

**判的是"这条信息是不是真的"，不是"这篇稿子是不是软文"。**

命中软文 / 推广稿 ≠ 该条信息作废。旧规则把"稿件属性"误当成"信息属性"，导致中文检索池
（软文密度天然高）被系统性过度淘汰。实测后果（2026-09-23 统计）：

| 指标 | 7月 | 8月 | 9月 |
|---|---|---|---|
| 含国内信源条目占比 | 72.5% | 39.0% | **29.0%** |
| Google 相关条目占比 | 0% | 20.3% | **38.7%** |
| 日均条目数 | 3.33 | 2.81 | **1.82** |

本文件即为纠偏。凡与旧规则冲突处，一律以本文件为准。

## 1 · 软文三级分类处置（强制：先分类再处置，禁止跳过分类直接删）

| 类 | 特征 | 处置 |
|---|---|---|
| **A 类 · 纯自夸无信息量** | 通篇自吹，无具体事实 / 数据 / 时间 / 事件（如"XX 成为 GEO 标杆""GEO 服务商 TOP10 榜单"且无第三方数据支撑） | **整条删除** |
| **B 类 · 软文外壳 + 真实事实内核** | 服务商 / 企业口吻，但内含可溯源的具体事实（某平台某日上线某机制、某项实测的具体数字、某标准的具体编号与发布方） | **禁止整条删除**。剥离事实内核 → 用该事实关键词重新检索独立中立报道 → **换源后正常入报**；确无独立源时允许保留该软文源链接，但须在标题或摘要中标注「（信源为企业发布稿）」 |
| **C 类 · 一手实测 / 研究** | 服务商或技术社区发布，含具体方法论与可复核数据（如"65 题 × 5 模型 × 联网的 650 次 AI 回答引用信源结构实测"） | **直接收录**，不得因"发布主体是服务商 / 云厂商社区"而剔除 |

**C 类说明**：GEO 行业的一手引用数据只有具备批量调用条件的服务商 / 技术社区能产出，
综合媒体不产这类内容；此类是方案商价值最高的「行业方法论」素材。
判据看【是否有可复核的数字与方法】，不看【谁发的】。

## 2 · 换源义务（B 类强制动作，不可省略）

任何因"疑似软文"准备剔除的候选，必须先执行**至少 1 次换源检索**
（用事实内核关键词：标准编号、平台机制名、实测结论短语），换到独立中立源则入报。
**只有"换源失败 且 属 A 类"才允许删除。禁止"看到服务商域名就删"的懒剔除。**

阿里云开发者社区、掘金、少数派、爱分析、亿邦动力、亿欧、财新、第一财经、21世纪经济报道、
每日经济新闻、证券时报、中国经营报、澎湃新闻、南方周末、极客公园、DeepTech、数据猿、199IT、
艾瑞网、易观，以及 IDC / QuestMobile 等研究机构公开报告页、
中国信通院 / 中国人工智能产业发展联盟（AIIA）等官方与行业组织发布页。

- **白名单外 ≠ 不可用**：白名单只是"优先采信"清单，**不在名单内不得作为删除理由**。
  名单外信源按三项判定：① 可溯源（有明确发布主体与日期）② 有可核验信息量（具体数字 / 机制 / 时间）③ 用户可访问。三项通过即可采用。
- **反软文判据收紧为"内容特征"而非"主体身份"**：只因发布主体是 GEO 服务商 / 云厂商社区 / 企业公众号就剔除，属**违规剔除**；真正的删除判据是「无第三方可核事实 + 通篇推销（留资表单 / 咨询电话 / 课程售卖）」。

## 4 · 平台动态边界修正

被排除的**仅限**「通用履约 / 交易 / 生态能力」发布（开放 Agent 接入、支付与订单基建、寄快递 / 租房租车、C 端会员收费）。

**下列情形明确属于「平台动态」，必须收录，不得以"模型更新 / 产品发布"为由排除：**

1. 模型对**第三方内容的检索机制**升级（联网检索深度、可调度子 Agent 数、可交叉核验网页数、检索并发策略）
2. **证据溯源 / 引用标注 / 权威信源优选**机制的引入或调整（"证据溯源""权威信源检索""时效判断""数据核验"）
3. 引用 / 收录 / 排序 / 推荐位的**规则与权重变更**
4. 爬虫协议、robots、收录周期变更

**判定口诀**：主语是被优化平台 **且** 变更改变"第三方内容如何被找到 / 选中 / 引用 / 呈现" → 平台动态；
主语是被优化平台但只是"自己多了什么功能 / 能卖什么" → 不纳入；主语是做 GEO 的工具 → 新技术 / 市场动态。

> 2026-09-23 教训：豆包 2.1 Pro 0915 强化证据溯源与权威信源检索，曾被误当模型更新排除，实为教科书级平台动态，已按发布日 9/16 补录。

## 5 · 去重判据限定为"同一事件"

去重只指"同一具体事件 / 同一发布动作"与"标题 / 核心内容高度雷同"；
**不得因"同一发布主体 / 同一服务商系列稿"而整类去重**——同主体的不同事实
（两次不同实测、两个不同标准、两个不同平台的机制变更）应分别收录。

## 6 · 反「软文矩阵 / 同源多投」条款

（防止白名单扩容被反向利用 · 2026-09-23 实测新增）

当同一服务商把**同一套话术**（同一份"六维框架 / TOP 榜 / 全景测评"，结论内定指向自己）
以不同标题同步投放到多家白名单媒体（如 IT之家、凤凰网科技、今日头条、搜狐号）时：

- **不得因"发布主体在白名单内"就直接采信**——判据仍是内容特征：通篇结论指向同一服务商、
  无第三方可复核数据、或虽引用第三方数据（标准编号 / 行业报告数字）但仅作背书不作论证的，
  一律判为**矩阵软文（B 类的子类）**。
- **处置**：只保留其**事实内核**（如标准编号 AIIA/T 0277-2026、易观 / 艾瑞 / CNNIC 的市场规模与占比口径），
  并**换源到一手出处**（信通院官网 / 报告原文 / 标准原文）后方可入报；
  换不到一手源则删除，**不保留软文源链接**；多标题多站点同一话术视为同一事件，**最多收 1 条**。
- 反之，真正的一手实测（方法可复现：问题集 / 模型清单 / 样本量 / 统计口径 / 局限说明，
  结论不含自我推销）按 C 类直接收录，不得因"云厂商社区 / 技术社区"属性剔除。
