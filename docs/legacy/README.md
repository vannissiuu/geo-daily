# 历史资料归档（仅供参考）

本目录存放「GEO 行业动态日报」在 WorkBuddy（飞书输出）时期的原始资料，迁移到本仓库时一并归档。**这些文件不再生效；现行规则以仓库根目录的 `rules/` 和 `config/` 为准。**

| 文件 | 是什么 |
| --- | --- |
| `_automation_prompt_new.md` | 旧定时任务的完整任务说明（采集、筛选、飞书推送流程） |
| `SOURCE_RULES.md` | 旧版信源与软文处理规则（其核心语义已并入 `rules/02`） |
| `C_CAT.md`、`C_SRC.md` | 旧网站/文档里的「分类说明」「信源说明」两段固定文案 |
| `gen_geo_doc.py` | 旧的飞书文档生成脚本 |
| `GEO每日动态_数据.md` | 旧的每日动态数据（Markdown 格式），已由 `tools/migrate_legacy.py` 迁入 `data/daily/` |
| `GEO_周度总结_当前.md` | 旧的周度总结快照，已迁入 `data/weekly/` |

说明：

- 因仓库公开，飞书用户标识、飞书文档链接、本机用户名等已替换为 `[已脱敏]`，所以其中涉及飞书的命令无法直接运行。
- 运行台账（`memory.md`）含身份信息，未收录。
- 旧文件里的飞书、HTML、`lark-cli` 推送、逐日补跑等做法已在新流程中废弃，详见根目录 `CHANGELOG.md`。
