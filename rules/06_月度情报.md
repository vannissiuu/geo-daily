# 06 月度情报（Part 4）

> 本文件管：每月第一个工作日生成「上月」月度情报的触发与自愈、选条与写法、`data/monthly/YYYY-MM.json` 格式与自动检查。
> 素材来自 `data/daily/*.json`（`04`）；允许重新打开所引用条目已核验过的链接补充细节（第 3.4 节）。分类含义见 `03`，平台取值见 `03` 第 3 节。
> 版式定稿依据：用户 2026-11-12 提供的《AI 行业动态情报提取报告（2026.08–11）》样式，并于同日确认：每月第一个工作日生成、允许回开原链接补细节、日报放开平台用户规模数据采集（`02` 0A.3b）。

## 1 触发与范围

1.1 **触发日**：每月第一个工作日（周一至周五，法定节假日照常；与日报同一次运行）。`tools/prepare_run.py` 输出 `monthly` 字段：当天为当月前 7 个自然日内的工作日时给出 `due`（上月）与 `heal`（上上月），各带 `exists` / `needed`。
1.2 **自愈**：`due.needed=true` 即生成——第一个工作日漏跑，则在当月第 7 日前的下一次运行补生成；`heal.needed=true` 时先补 `heal` 这 1 份，更早缺失的月份不回溯。
1.3 **范围**：`data/daily/` 中 `date`（日报所属日期）落在该自然月内的条目，**不是 `published`**。当月日报不归上月。
1.4 已存在的月度情报**不覆盖**（重跑须显式指令）。区间内 0 条：仍生成文件，`regions` 各节为空、`metrics` 与 `summary` 为空数组，`note` 写"本月无新增动态"。

## 2 结构（用户已确认，不可增删段落）

| 段 | JSON 字段 | 站点呈现 |
|---|---|---|
| 页头 | `title`、`lede`、`metrics` | 标题「{YYYY} 年 {M} 月 GEO 行业情报」、一句导语、3 个关键数字卡 |
| 国内 | `regions.国内` | 一句 `desc`；两节：`insight`「行业洞察报告 · 平台用户规模与市场趋势」、`rules`「国内平台规则变化」 |
| 海外 | `regions.海外` | 同上：`insight`「行业洞察报告 · 平台用户规模与市场趋势」、`rules`「海外平台规则变化」 |
| 小结 | `summary` | 「小结：三条主线」，恰好 3 条 |

- **两节的取材口径**：
  - `insight`（洞察报告）：被优化平台的用户规模 / 使用量（DAU·MAU·WAU、查询量、人均次数与时长、份额），第三方机构的市场规模 / 生态图谱 / 行业报告，有方法和样本的引用研究（`行业方法论` C 类一手实测、`市场动态` 中的报告与规模数据）。
  - `rules`（规则变化）：被优化平台自身的引用 / 收录 / 爬虫 / 广告 / 购物 / 治理规则变更（`平台动态`），以及监管、标准、执法、平台自律公约（`行业政策`）；基础设施侧会改变抓取或接入规则的（Cloudflare、WordPress 等，`新技术`）可酌情收入。
  - 单纯的融资、产品发布、观点评论不进本报告（它们留在日报与周结里）。
- **分组**：每节是 `groups` 数组，组名可为空字符串（不显示组标题）。海外 `rules` 通常按平台系分组（如「Google 系」「OpenAI / ChatGPT 系」「Meta · 微软 · 其他平台」「监管与标准」），国内可按「平台」「监管与标准」分组；组内按日期倒序。
- **条数**：全文 12–40 条（不足 12 条时如实少写，不凑数；> 40 告警）。四节中某节当月确无合适条目时 `groups` 为空数组，站点显示"（本月无相关条目）"。

## 3 写法

3.1 **条目**：`{ref, title, body}`。`ref` 为该月内日报条目 `id`，**每个 id 全文只出现一次**；日期、链接、分类由程序从日报条目回填，JSON 里不写 URL。
- `title`：一句中文，≤ 60 字，可比日报标题更提炼；平台规则类须含平台名或别名。
- `body`：≤ 220 字（不计 `**`），写"发生了什么 + 关键数字 + 对 GEO 意味着什么"；关键数字用 `**…**` 加粗（每条 ≤ 3 处）；不得含 URL、Markdown 链接、`[分类]` 标签或编号前缀。

3.2 **`metrics`**：恰好 3 个 `{value, unit, caption, ref}`，从当月条目中挑对方案商最有分量的数字（用户规模、市场规模、覆盖率 / 份额优先）。`value` 为纯数字串（如 `137`、`88`、`1.2`），必须原样出现在 `ref` 条目的 `title` / `summary` 或本报告中该 `ref` 的 `body` 里；`caption` ≤ 40 字，说清口径与主体。

3.3 **`lede`** ≤ 80 字、每个 `desc` ≤ 80 字、`summary` 每条 `{title, text}`（`title` ≤ 20 字，`text` ≤ 160 字）：概括性、带判断、面向方案商；`summary` 三条分别对应本月三条主线，`text` 中的事实须能在本报告条目里找到。三者都不加编号、分类前缀和链接。

3.4 **回开原链接补细节（已授权）**：为让 `body` 比日报 150 字摘要更完整，主会话可 WebFetch 重新打开所引用条目的 `links` 中的链接（仅限这些已核验过的 URL，原样打开），补充同一事件的数字与细节。约束：
- 只补**同一事件**的事实，不引入新事件、新链接；页面打不开、内容已改或与日报记录矛盾时，以日报条目为准，不补。
- 预算：每期 ≤ 25 次 WebFetch，计入当天 `data/runs/{D}.json` 的 `webfetch_calls`，并在该文件 `monthly_log` 中记录 `{month, refs, reopened: [url], failed: [url]}`。
- 重新打开不改变日报原文件（历史日报一律不改）。

3.5 **选条原则**：按"对 GEO 方案商的影响力"挑，不按分类配额；同一事件多日跟进（如 Meta 商业条款三次变化）合并为一条，`ref` 取最新或最关键的一条，其余进展写进 `body`；国内、海外都要有，国内素材少时如实少写。

3.6 **后续进展**：`body` 末尾可用一句话注明截至生成日的后续进展（如"11 月 9 日已宣布暂停"），该进展必须是仓库中已收录的日报条目（可跨月），不得引用未收录的消息。

## 4 JSON 格式（`data/monthly/YYYY-MM.json`）

```json
{
  "month": "2026-10",
  "period": ["2026-10-01", "2026-10-31"],
  "generated": "2026-11-02",
  "title": "2026 年 10 月 GEO 行业情报",
  "lede": "一句导语",
  "metrics": [{"value": "137", "unit": "亿元", "caption": "沙利文估算 2026 年中国 GEO 市场规模", "ref": "2026-10-27-05"}],
  "regions": {
    "国内": {"desc": "一句话", "insight": {"groups": [{"name": "", "items": [{"ref": "2026-10-27-05", "title": "", "body": ""}]}]},
             "rules": {"groups": []}},
    "海外": {"desc": "一句话", "insight": {"groups": []}, "rules": {"groups": []}}
  },
  "summary": [{"title": "主线一", "text": ""}],
  "stats": {"month_entries": 74, "selected": 30, "reopened": 0},
  "note": "仅本月 0 条时填"
}
```
- `stats.month_entries` = 该月日报条目总数；`selected` = 全文条目数；`reopened` = 回开链接次数。
- 条目归哪个区由日报条目的 `region` 决定：国内条目只能放在 `regions.国内`，海外只能放在 `regions.海外`。

## 5 自动检查（`tools/check_data.py`，M01–M09）

| 编号 | 检查项 | 处置 |
|---|---|---|
| M01 | JSON 可解析；必填字段齐全；文件名 = `month`；`period` 为该月首末日 | 阻断 |
| M02 | 每个 `ref` 存在且其日报日期落在该月；全文 `ref` 不重复 | 阻断 |
| M03 | 条目 `region` 与所在区一致 | 阻断 |
| M04 | `metrics` 恰好 3 个（0 条月为空）；`ref` 在该月；`value` 可在 ref 条目或其 `body` 中原样找到 | 阻断 |
| M05 | `summary` 恰好 3 条（0 条月为空），`title`/`text` 非空 | 阻断 |
| M06 | 文本不含 URL / Markdown 链接，不以编号或 `[`/`【` 开头 | 阻断 |
| M07 | 长度：`title` ≤ 60、`body` ≤ 220、`lede`/`desc` ≤ 80、`caption` ≤ 40、`summary.text` ≤ 160 | 阻断 |
| M08 | 全文条数 12–40；`rules` 节中平台动态 / 行业政策条目占多数；`insight` 节中行业方法论 / 市场动态占多数 | 告警 |
| M09 | 同月只有一个文件；月份不晚于最新日报所在月 | 阻断 |

## 6 网站

站点第四个标签页「月度情报」，按月倒序，左侧（窄屏为下拉）选月份；版式：页头关键数字卡 → 国内（洞察 / 规则）→ 海外（洞察 / 规则，按组）→ 小结。每条左侧显示日期（主链接 `published`，无则日报日期），右侧标题、正文（`**` 渲染为加粗）与该条目全部链接。国内用红色系、海外用蓝色系标识，沿用站点深浅主题变量。
